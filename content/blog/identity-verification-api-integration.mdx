This article is part of Certifyd’s historical security editorial archive. It was revised in October 2026 to remove unsupported claims and earlier product promises. It is not a specification of currently available Certifyd features.


## Evaluate the actual API contract

Check what the service returns, its source, error handling, evaluation evidence and intended use. A successful response is not proof that the result is suitable for every legal or business decision.

This article does not substantiate its earlier OCR accuracy figure, issuing-authority integrations or production Certifyd identity API. Assess those capabilities from current technical documentation and verified service scope.

## Keep employer requirements explicit

The [Home Office employer guide](https://www.gov.uk/government/publications/right-to-work-checks-employers-guide) defines eligible right-to-work methods and employer actions. A generic API identity score is not a prescribed employer result or automatic statutory excuse.

Certifyd currently helps organise [worker evidence and review actions](/platform/records/). Historical descriptions of biometric, liveness or universal database integrations should not be used as an implementation specification or availability promise.
